# Ganzton (Whole Tone) – Debussy / Impressionismus
# Prinzip: Jeder Schritt ist eine große Sekunde → vollständige Symmetrie
# Nur 2 verschiedene Ganzton-Skalen möglich:
#   Skala 1: C  D  E  F#  Ab  Bb
#   Skala 2: Db Eb F  G   A   B
# Charakter: schwebend, ohne Tonikagefühl, traumhaft

# ═══════════════════════════════════════════
#  GANZTON-SKALA 1: C D E F# Ab Bb
# ═══════════════════════════════════════════

# Augmentierte Dreiklänge (alle äquivalent innerhalb der Skala)
chord Caug    60 64 68    # C augmentiert  = C–E–G#
chord Daug    62 66 70    # D augmentiert  = D–F#–A#
chord Eaug    64 68 72    # E augmentiert  = E–G#–C

# Dominant 7 #5 (der typische Ganzton-Akkord: Debussy, Ravel)
chord C7s5    60 64 68 70   # C7#5  = C–E–G#–Bb
chord D7s5    62 66 70 72   # D7#5  = D–F#–A#–C
chord E7s5    64 68 72 74   # E7#5  = E–G#–C–D
chord Ab7s5   68 72 76 78   # Ab7#5 = Ab–C–E–Gb
chord Bb7s5   70 74 78 80   # Bb7#5 = Bb–D–F#–Ab

# Ganzton-Quartenakkorde (Debussy-typisch)
chord Csus2   60 62 67    # C–D–G  (Ganzton-Fragmente)
chord Gsus2   67 69 74    # G–A–D

# ═══════════════════════════════════════════
#  GANZTON-SKALA 2: Db Eb F G A B
# ═══════════════════════════════════════════

chord Dbaug   61 65 69    # Db augmentiert = Db–F–A
chord Ebaug   63 67 71    # Eb augmentiert = Eb–G–B
chord Faug    65 69 73    # F augmentiert  = F–A–C# (= Db aug)

chord F7s5    65 69 73 75   # F7#5  = F–A–C#–Eb
chord G7s5    67 71 75 77   # G7#5  = G–B–D#–F
chord A7s5    69 73 77 79   # A7#5  = A–C#–E#–G

# ═══════════════════════════════════════════
#  GANZTON-BEZIEHUNGEN
# ═══════════════════════════════════════════

# Innerhalb Skala 1: alle Akkorde gleichberechtigt (schwebend, kein Zentrum)
neighbor Caug   Daug    1.0

neighbor Ab7s5  Bb7s5   1.0
neighbor Bb7s5  C7s5    1.0   # Dominanten-Zyklus in Skala 1

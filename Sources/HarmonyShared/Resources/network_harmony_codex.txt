# The Harmony Codex (Song) – Steven Wilson, 2023
#
# Struktur des Stücks: eine harmonische "Infinite Staircase"
#   X_dur → X_moll → (X + Quinte)_dur → (X + Quinte)_moll → …
#
# Immer dasselbe Muster, immer um eine Quinte aufwärts:
#   Dur-Akkord → gleicher Akkord Moll → Quinte höher Dur → …
#
# Alle 24 Akkorde (12 Dur + 12 Moll), nach 9 Minuten wieder am Anfang.
# Kein Tonikagefühl – nur das ewige Weitersteigen, wie eine Shepard-Tonleiter.
#
# E → Em → B → Bm → F# → F#m → C# → C#m → Ab → Abm
#   → Eb → Ebm → Bb → Bbm → F → Fm → C → Cm → G → Gm
#   → D → Dm → A → Am → (E)
#
# Verbindungen: nur vorwärts in der Kette (kein Zurück = keine Auflösung).
# Das erzeugt das "immer weiter, nie ankommen"-Gefühl des Stücks.
